# Web Dev II

This is your Official GitHub repository for Web Dev II. All assessment work for this module must be submitted to this repository. You can also keep your in-class work in this repository if you would like to.

Over the course of the module, you should keep your repository well organised. You should commit changes in your repository often (e.g. after completing a specific task), use descriptive commit messages, and regularly push your code back to GitHub.

A folder has been provided for each assessment task, which will contain any additional files you may need. You should submit your work for each assessment task to the corresponding folder in your repository. In other words:

* Please submit Clone Task 1 to [`/assessment-1-clone-tasks/task-1-layout-in-react`](/assessment-1-clone-tasks/task-1-layout-in-react)
* Please submit Clone Task 2 to [`/assessment-1-clone-tasks/task-2-responsive-layouts`](/assessment-1-clone-tasks/task-2-responsive-layouts)
* Please submit the Multi-Device Application to [`/assessment-2-multi-device-application`](/assessment-2-multi-device-application)

**Only code pushed to your GitHub repository before the assessment deadline will be marked. Ensure you give yourself enough time before your final push.**
